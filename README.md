## Project Overview

AI Career Guidance System is an AI-powered web application designed to help students discover suitable career paths based on their interests, skills, educational background, and career goals. The platform provides personalized recommendations, career insights, and guidance to help students make informed decisions about their future.

The application offers an interactive and user-friendly experience, allowing users to explore career opportunities and receive AI-generated suggestions tailored to their profiles.

## Installation Steps

### 1. Clone Repository

### 2. Open Project Folder

cd ai-pathfinder-pro-50

### 3. Install Dependencies

npm install

### 4. Run Development Server

npm run dev
